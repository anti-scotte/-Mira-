# Mira 运行指南

1. 将预注册规则和五位成员配置导入同一个 Mira 项目。负责人登记规则版本、人工确认凭证及实际模型与 Skills。按第一阶段提示词派工。
2. 数据岗按 inputs/downloads.csv 下载并校验文件，在盲态下建池。单独的参考脚本调用为 `python code/make_ref.py WBM.csv.gz pool.csv ref_hull.csv`。pool.csv 需要 material_id 列，对应候选池须先由签认的范围规则建立。参考脚本使用 pandas 与 numpy；历史数据清单记录版本为 pandas 2.2.3、numpy 1.26.4。
3. 排序岗和共识岗分别核对输入、正式代码和输出。当前代码回收情况见 rules/deviations.md；合成样例用于测试逻辑。需正式复跑时先补齐生产入口，或依协议立项记录修订。在共享目录交接时由接收岗实际打开文件并复验指纹。
4. 收齐 S、C 签认及冻结回执后使用第二阶段提示词。揭晓岗先验签和运行全体独特原型的冠军 F1 自检，再计数；另一位队员在独立会话复算。
5. 只需核对七档名单中的交集时，可用仓库首页的 Python 命令，输入原运行导出的预算 JSON。此操作只读材料 ID。
