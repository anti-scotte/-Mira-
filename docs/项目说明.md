# 给只有 20 个复核名额的材料研究生

组会前一晚，一名研究生要从两万多个含氧结构中交一份 20 项复核名单。沿用熟悉的模型很快，却解释不了换模型会换掉哪些材料；逐一做新的 DFT 计算又超出了预算。我们把这个决定变成一次可重复的历史回测：在同一候选池冻结两份名单，按材料编号接回公开的 DFT 参考值，直接数出换掉的名额有没有带来额外命中。

**做成的标准。** 排序阶段隔离标签，名单有冻结指纹，冠军 F1 与模型卡 0.935 的绝对差 ≤ 0.02，另一位队员可以从原件复跑关键分析。数据为 Matbench Discovery 的模拟材料及模型预测；代码生成排序和统计。研究对象与数据许可见仓库首页。

**结果。** 20 个名额中有 18 个共同入选，另外两边各有 2 个独选。四个独选全部满足 DFT 稳定判据，因此两策略各中 20。2,000 个名额时，共识比单模型多中 11 个，占预算 0.55 个百分点。在这个池和预算下能具体指出换了谁、收益多少。其他材料体系仍待验证。

**验证。** 揭晓后修正预测凸包距离的参考能公式。全体系独特原型 215,488 项，TP 30,939、FP 2,326、TN 180,220、FN 2,003，F1 为 0.9346141647，与模型卡相差 0.000386。原始数据及七档冻结名单已在本地复算；方向一第二轮主算及 Mira 独立复核均通过预注册门槛，后续队友 R1 已完成冻结名单复算及签认，见[队友 R1 复核摘要及交付件](../evidence/reviews/teammate-r1/复核摘要.md)。新旧版本、修改原因、来源会话和文件位置见 README 与 rules/deviations.md。

**3–5 分钟演示。** 用半分钟交代研究生的 20 个名额，打开四行差集表说明两种排序换了谁；按 README 运行 code/recount.py，展示 F1 四格计数、前 20 和前 2,000 的差异；最后打开冻结回执，说明从哪份名单复算以及结论适用的范围。
