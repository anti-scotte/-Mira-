# 【B·组会前一晚｜材料科学】有限预算下预测模型的决策组

评审导读：[历史溯源与版本沿革](历史溯源与版本沿革.md) · [术语与判定口径](术语与判定口径.md)

**问题与最初标准**　在先做机器学习初筛、后做 DFT 复核的研究中，单模型冠军 S 和 15 模型共识 C 各能用同样的名额找到多少稳定候选？预注册要求锁定候选、规则和名单，独立复算前20命中数；冠军全体系独特原型 F1 与模型卡相差至多 0.02。完整规则及各环节验收见 inputs/downloads.csv 与 rules/9-预注册规则.md。

**来源与性质**　Matbench Discovery 公开 WBM 数据与模型预测。WBM 共 256,963 项，独特原型 215,488 项；含氧且 15 模型共同覆盖 23,821 项。形成能和稳定性依据 DFT 模拟，模型预测为计算生成值，候选排序、共识和统计由脚本生成。没有实验测量或新增 DFT 计算。参考能从已发布量重构。数据归属原作者，数据集采用 CC BY 4.0，逐文件来源与校验值见下载清单。数据 DOI 10.6084/m9.figshare.22715158；预测归档 DOI 10.6084/m9.figshare.28187990。

**分析过程**　S 采用 dpa-4.1-max-oam-pft 的预测凸包距离；C 采用各候选在 15 模型上该距离的中位数。盲态排序按分数升序，同分用冻结配置规定的哈希顺序。冻结两份排序和七档前缀后，以材料 ID 关联 WBM，原始 DFT 凸包距离 ≤ 0 eV/atom 计为命中。模型使用归档预测，未重新训练。方向一仅复核 K=20 的四个独选和 F1。

**结果**　预算 K 为 20、50、100、200、500、1000、2000 时，S 的命中数依次为 20、49、99、198、489、980、1935，C 为 20、50、99、199、490、982、1946。前20有18个共同候选，另外两边各有2个独选，4个均命中。K=2000 时共识多中11个，即命中率高0.55个百分点。K≥100 各档差值均小于预注册的5个百分点。结论限于该含氧池、版本、预算与稳定性判据；名单重合率不用于估计命中率。

**验证与人工干预**　早期三模型草案与本轮执行配置冲突；当前排序以15模型的签认运行配置为依据。历史入口缺失后，以 2.0.0 重建脚本生成名单。揭晓后的本地修订纠正了预测参考能公式，保留冻结名单、原脚本、原摘要和修订输出。正确参考能为 DFT 形成能减原始 DFT 凸包距离，预测距离为模型形成能减参考能。真实标签直接由原始 DFT 凸包距离判断。逐项执行证据及新旧文件见 evidence/reviews 和 evidence/superseded；具体修改者身份仅按原有记录归属。

**状态**　方向一第二轮按全体系 215,488 个独特原型复算，主算与 Mira 独立复核脚本均得到 F1=0.9346141647，与模型卡 0.935 相差 0.000386，满足预注册门槛 0.02。队友已在独立会话 R1 完成冻结名单复算并填写签认。见[队友 R1 复核摘要及交付件](../evidence/reviews/teammate-r1/复核摘要.md)。 排序复现的范围为已交接的含氧盲表。方向一复核岗从原始总体重建 S 子池时报告首位差异，子池筛选定义仍需对照；其复核环境也未独立重建 C 的全部模型分数。
