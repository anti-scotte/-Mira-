# 排行榜选模指标会改变多少复核名额的收益？

此页为原任务记录。当前复跑请使用[整合版固定模式提示词](../workflow/指标敏感性专家团/03_配合模式首轮提示词.md)或[自由 Lead 提示词](../workflow/指标敏感性专家团/04_自由Lead首轮提示词.md)。

## 发给新窗口 Lead（全文可粘贴）

使用已配置的材料科学专家团，由 Lead 自由编排。请直接创建执行计划。上一窗口在创建计划前停止，原因未取得；这一轮承接以下已确认决策。研究对象是原先按 F1 筛入的 15 个模型共同覆盖的 23,821 个含氧候选。目标是回答同一研究者手握 K 个复核名额时，换选模指标会换掉哪些材料、净增减几个 DFT 稳定候选。这是主实验揭晓后的敏感性分析。

1. 输入岗定位解压后的复验工作空间。用 cards/、inputs/、results/、raw/ 和 reference/预注册规则.md。若只有“15张模型卡与规则”补包，还需从复验工作空间绑定盲表、参考能、模型清单、冻结名单、冻结回执和揭晓用 WBM 原始文件。inputs 下按文件名查找 unlabeled_candidate_pool.csv、reference_hull_energies.csv、model_manifest.json。核对 RUN-20261121-STAGE2-01 的 freeze.json 与 budget_lists_7tier.json 及已登记输入的 SHA-256。记录实际相对路径和哈希。
2. 选模岗仅读取固定版本模型卡 metrics.discovery.unique_prototypes 的指标。F1 最大，沿用预注册第 2 节的并列规则（DAF 高者优先，再按模型名字母序）；已登记冠军 dpa-4.1-max-oam-pft，F1 0.935。DAF 最大，清单记录 dpa-4.1-max-oam 为 6.16，允许换人。MAE 最小，单位 eV/atom。按卡片公布精度保留所有并列最低模型，DAF 并列同样全保留；逐卡列值以解决历史对话的 0.017/0.018 分歧。缺卡可按清单固定 commit 和路径取原文并留指纹，缺字段登记有效覆盖。禁止用本地标签反选冠军。同模型只生成一次名单，保留全部指标来源。
3. 排序岗沿用盲表、参考能和原排序及同分规则，生成各模型在 K=20、50、100、200、500、1000、2000 的有序名单。冻结新增名单及哈希后交揭晓岗。固定参照 S、C 来自同一原冻结件，保留原顺序。C 实际为逐材料取 15 个模型预测凸包距离的中位数后排序；原协议写名次中位数。摘要和方法均注明这一已登记偏离。
4. 揭晓岗按 material_id 对齐 WBM 公开 DFT 标签，有限的 e_above_hull_mp2020_corrected_ppd_mp ≤ 0 eV/atom 计命中。核对 ID 唯一性与标签覆盖。每档对 S、C 分别给出交集数、换掉名额数 K−交集数、Hits@K、命中差（扩展减参照）及命中率差（100×命中差/K，百分点）。K=20 列出双侧独有材料 ID、名次、DFT 距离与命中标志。复核岗独立核算换入命中数减换出命中数等于总命中差，给出复跑命令。MAE 并列各列结果及范围。
5. 脚本、输入索引、模型卡指标表、冻结名单、七档比较表、K=20 明细、复核记录及摘要写入 outputs/metric_sensitivity/。摘要分别回答哪些指标换了模型、换了几个材料、多中或少中几个。成本缺实测时由使用者权衡额外预测成本，不给出普适最优模型。原主实验的 F1 自检与命中记录只作背景。本轮引用公开模拟数据，命中指按 DFT 判据稳定。请报告实际运行和复核状态。如遇影响正确性的输入缺失或哈希冲突，列具体文件、已查路径和受影响步骤；其余步骤按上述决定推进。
