# 术语与判定口径

读结果时先看分母。**20/20** 统计某份前 20 名单里有几项命中；**F1 = 0.934614** 评价冠军模型在 215,488 项上的稳定分类。两项指标回答不同问题。

| 术语 | 在本项目中怎么用 |
|---|---|
| Matbench Discovery、WBM | 前者是材料发现基准，后者是本次使用的假想晶体数据集。WBM 汇总有 256,963 项，每项用 material_id 连接预测和 DFT 参考值。同一化学式可以对应不同结构。 |
| 独特原型、共同候选池 | unique_prototype=True 是原始数据中的筛选标记，全化学体系共有 215,488 项，用于 F1。再按含氧和 15 个模型共同覆盖筛选，本轮排名用 23,821 项。 |
| DFT、真值、稳定 | DFT（密度泛函理论）给出计算参考能量。这里的“真值”是公开的 DFT 参考标签。按项目使用的带符号凸包距离 ≤ 0 eV/atom 记为稳定；评价的是这个计算判据，实验可合成性另待验证。 |
| 形成能、参考凸包能量、凸包距离 | 形成能按每原子计。参考凸包能量代表相同成分的稳定参照能量。能量相对该参照的差称为凸包距离。eV/atom 表示电子伏特每原子。具体列和公式见下文。 |
| S、C、冠军 | S 按预选单模型冠军 dpa-4.1-max-oam-pft 的预测距离排序。C 对同一材料取 15 个模型预测距离的中位数再排序。两者均按分数从低到高取前 K。冠军依据模型卡 F1 选定。 |
| K、Top-K、预算 | K 是可复核的材料数，Top-K 是相应排序的前 K 个材料 ID。七档为 20、50、100、200、500、1000、2000。“预算”以名额计。 |
| 交集、独选、重合率 | 同时出现在两份名单中为交集；只出现在其中一侧为该侧独选。重合率 = 交集数/K。前 20 共有 18 个，重合率 90%。 |
| Hits@K、命中率、D20 | Hits@K 是前 K 中 DFT 稳定的个数，命中率 = Hits@K/K。D20 = 共识前20命中数 − 单模型前20命中数。本轮各自独选的两个都命中，D20=0。 |
| 百分点、随机期望 | 两个比例直接相减用百分点。共识在 K=2000 多中 11 个，命中率高 11/2000 = 0.55 个百分点。均匀随机选 K 个的期望命中数为 K × 池内稳定比例。 |
| TP、FP、TN、FN | 以“稳定”为正类。预测稳定且 DFT 稳定为 TP，预测稳定但 DFT 不稳定为 FP；预测不稳定且 DFT 不稳定为 TN，预测不稳定但 DFT 稳定为 FN。 |
| 精确率、召回率、F1、模型卡、自检门槛 | 精确率 = TP/(TP+FP)，召回率 = TP/(TP+FN)，F1 = 2TP/(2TP+FP+FN)。模型卡记录发布方基准值 0.935。预注册自检要求 F1 绝对差 ≤ 0.02；方向一脚本另测 0.0005，仅作交叉参考。 |
| 预注册、盲排、冻结、揭晓 | 事先登记规则；屏蔽逐材料 DFT 标签生成名单；固定有序 ID 和文件指纹；最后按 ID 接回真值并计数。 |
| SHA-256、MD5、运行编号 | 前两者都是由文件字节计算的校验值，用于核对文件版本。运行编号标识一次执行，配合输入指纹、脚本和输出查来源。 |
| Workflow、Agent、Lead、Skill | 分别指工作步骤及交接顺序、承担具体任务的成员、统筹交接的负责人、配置供成员使用的技能。配置表记录可用技能，实际调用看会话记录。 |
| 程序自检、独立复算、真人签认 | 程序自检对照预注册门槛；方向一的独立复算由另一 Mira 岗位用独立实现核对；真人签认要求另一位队员亲自复跑并记录结果。 |

## 对照原始数据列

- 真实距离取 WBM 的 `e_above_hull_mp2020_corrected_ppd_mp`；真实稳定条件为该列 ≤ 0。
- 参考能 = WBM 的 `e_form_per_atom_mp2020_corrected` − 真实距离。
- 预测距离 = 冠军预测文件的 `e_form_per_atom` − 参考能；预测稳定条件为该距离 ≤ 0。盲排使用事先交接的参考能表，揭晓复算才从原始列核对公式。
