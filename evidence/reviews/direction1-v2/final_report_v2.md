## 二、口径与判据

样本域为原始 WBM（`2023-12-13-wbm-summary.csv.gz`）中 `unique_prototype == True` 的全部行，共 **215,488** 个材料，覆盖全部化学体系，与冠军模型 `dpa-4.1-max-oam-pft` 的预测文件按 `material_id` 一对一连接（缺失 0、重复 0、对齐后非有限值 0）。

真实稳定判据是原始 DFT 凸包距离：真值正类为 `e_above_hull_mp2020_corrected_ppd_mp ≤ 0 eV/atom`。预测侧先算预测凸包距离 `predicted_distance = e_form_per_atom − (e_form_per_atom_mp2020_corrected − e_above_hull_mp2020_corrected_ppd_mp)`，再以 `predicted_distance ≤ 0` 判为稳定。指标为 `F1 = 2·TP/(2·TP + FP + FN)`。两侧比较的量都是凸包距离（单位 eV/atom），而 `absolute_difference` 是 F1 差值的绝对值，属无量纲量，不携带 eV/atom 单位——这一点在 JSON 与本节都明确写出，避免把 F1 差当成能量差解读。

23,821 个含氧候选只用于名单命中分析：本轮实读 `unique_prototype=True` 中包含 O 元素的行恰为 23,821 个，与任务口径一致；这批含氧候选不构成 F1 的分母，也不参与四格判定，只用于回答「含氧体系在冻结名单里命中了多少」。

## 五、门槛的显式记录方式

原 `recheck.py` 以断言方式判定 F1 门槛，失败即中断，且不区分本轮输出目录，旧件残留因此难以从产物层面排除。修订脚本 `shared/recheck_v2.py` 改为显式记录：第 159 行以 `--f1-tolerance` 接收容差（默认 `DEFAULT_TOL = 0.5 × 10⁻³ = 0.0005`，取自模型卡末位的半单位，历史断言容差在可查证据中没有文档），第 175 行以 `passed = diff <= args.f1_tolerance` 计算布尔结论，随后把 `passed`、`f1_gate.tolerance`、`absolute_difference` 同时写入 `f1_run_result.json`、`stdout.log` 与报告摘要 `report_summary` 三处。因此本轮门槛结论是「记录下来的通过或失败」，而不是「没报错所以通过」。

这里有一个必须如实并列的口径差：用户预注册的门槛是 abs(F1 − 0.935) ≤ 0.02，而脚本内部默认容差是 0.0005。两个门槛都给出通过，但余量差别很大——按预注册 0.02，余量为 0.019614164665367678；按内部 0.0005，余量仅 0.0001141646653676771，属贴线通过。本报告的 F1 程序自检结论以预注册 0.02 为准，0.0005 只作交叉参考，不作为结论依据（独立复核报告 §预注册门槛结论 持同一立场）。若后续要求把 PASS 判定绑定到更严的容差，应当先书面确认门槛，再引用相应余量。
