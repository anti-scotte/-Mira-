## 复算口径与方法

复算从原始文件逐行读取，不经 pandas，也不复用任何既有脚本的解析层：

- 真值域：`2023-12-13-wbm-summary.csv.gz` 中 `unique_prototype == True` 的行，以 `material_id` 与冠军预测文件一对一连接。
- 标签：`e_above_hull_mp2020_corrected_ppd_mp <= 0`（float64，无容差）。
- 预测：`pred_dist = e_form_per_atom − (e_form_per_atom_mp2020_corrected − e_above_hull_mp2020_corrected_ppd_mp)`，判定 `pred_dist <= 0`。
- 指标：`F1 = 2·TP / (2·TP + FP + FN)`，Python float（IEEE754 binary64）直接相除，不四舍五入。

输入指纹在本轮由脚本实算，与 `shared/input_verification_v2.json` 登记一致：WBM gz `adbdd8b2…64dc54`、冠军 gz `4767371b…328eb`、`f1_hits_detail.csv` `980f1556291892279d17fac832e5fc283c433b8cd55ded364c01272c4fa79d5d`（后者与 `f1_run_result.json` 的 `hits_detail_sha256` 逐位相同）。

脚本可独立运行：`python3 independent_check.py`（全量复算）与 `python3 independent_check.py --capability-check`（能力自检，用 3 行合成数据验证计数逻辑：TP=2、FP=1、F1=0.8，符合手工预期）。以固定 `--run-dir` 连跑两次，除 `run_id`/`run_dir`/`generated_at_utc` 外全部字段逐位相同；把脚本复制到子目录、并从另一个工作目录启动再跑，四格与 F1 也完全相同，即结果确定、且不依赖脚本所在层级或当前目录。输入目录可用 `INDEPENDENT_CHECK_SHARED` 覆盖。
