## 2 独立重算过程与命令

复核脚本全部自写，未 import 上游脚本：`scratch/indep_review.py` 负责六段（输入实读、F1、S/C 命中、四行分歧、恒等式、上游 CSV 与 JSON 逐字段比对），`scratch/f1_probe.py` 负责对 F1 参考能定义做反证扫描。运行方式为在任务工作目录执行 `python3 scratch/indep_review.py` 与 `python3 scratch/f1_probe.py`，环境为 Python 3.11 / 纯标准库（`gzip`、`csv`、`math`、`hashlib`、`json`、`decimal`），未依赖 pandas，以免与上游的 pandas 路径共享任何实现细节。事实快照写入 `scratch/indep_review.json`，过程记录见 `scratch/review_notes.md`。

## 8 偏差清单（逐项可定位）

**偏差 1（阻塞）｜F1 数值与门槛结论错误。** 字段 `recheck_evidence.json → f1_check.f1` 与相关字段。期望值 **0.20473487310597854**，实际值 **0.9346141646653677**；同一组依赖字段 `f1_check.absolute_difference` 期望 **0.7302651268940215**、实际 0.0003858353346323229；`f1_check.passed` 期望 **false**、实际 true；`f1_check.tp/fp/tn/fn` 期望 **14174/91346/91200/18768**、实际 30939/2326/180220/2003；`f1_check.independent_recalculation.*` 同步错误（它声明 215488 行、非有限 0，但计数与我实测的同一 215488 行不符）。同时 `f1_check.conclusion_status` 写的"方向一脚本复算通过，待另一位…复核"不成立。定位：本条由第 3 节与 `scratch/f1_probe.py` 支撑，失败根因是参考能定义（`e_form_per_atom_mp2020_corrected` 已由我复现两次，替换为 `e_form_per_atom_wbm` 或未校正能亦无法达到记录值），需由负责 F1 修订的成员重检查 `recheck.py` 的公式与列名。

**偏差 2（阻塞）｜"实跑归档与旧件逐字段比对成立"的结论不能作为 F1 证据。** 字段 `recheck_evidence.json → field_comparison.byte_equal / consistent_count` 与 `execution.archived_result.sha256`。期望：归档结果应体现本轮独立实跑的可复现 F1；实际：归档与 513 B 旧件**字节完全相同**（同一 SHA-256 `07babb5c…bebe65e8`），字段零差异只是因为两者是同一份字节。该事实本身与我核对到的描述一致（无造假迹象），但其推论"复算通过"不成立，影响面同偏差 1。
