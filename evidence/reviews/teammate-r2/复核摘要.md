## 四、冠军 F1 的程序自检（先于名单计数）

口径为原始 WBM 中 `unique_prototype == True` 的全部行，实算 215,488 项，与预期 215,488 一致，覆盖全部化学体系。预测距离按 `d = 冠军 e_form_per_atom − (e_form_per_atom_mp2020_corrected − e_above_hull_mp2020_corrected_ppd_mp)` 计算，`d ≤ 0` 判为预测稳定；真实稳定为原始 `e_above_hull_mp2020_corrected_ppd_mp ≤ 0`。

| 指标 | 本轮实算 |
|---|---|
| n（unique_prototype=True） | 215488 |
| TP / FP / FN / TN | 30939 / 2326 / 2003 / 180220（和 215488） |
| 真值正类 TP+FN / 预测正类 TP+FP | 32942 / 33265 |
| Precision / Recall | 0.9300766571471517 / 0.9391961629530691 |
| F1 = 2·TP/(2·TP+FP+FN) | 0.9346141646653678 |
| abs(F1 − 0.935) | 0.00038583533463221187 |
| 门槛 abs ≤ 0.02 | 通过，余量 0.01961416466536779 |

边界敏感性：预测距离恰为 0 的行 0 个；真值侧与预测侧各用 `≤` 与 `<` 的三种替代组合（其余保持一致）一致数均为 211,159，四格在真值侧 `≤`／`<` 两种取法下不变，说明结果不依赖边界约定。含氧口径核对：`unique_prototype=True` 且化学式含 O 且至少含一种其他元素的材料恰为 23,821 个，与冻结池规模一致；该数只用于名单分析口径说明，不进入 F1 分母。

手算端到端单位核对（名次 1，`wbm-3-56891`）：`e_ref = 0.544327 − (−1.512202) = 2.056529 eV/atom`，冠军预测 `e_form = −3.5207 eV/atom`，`d = −3.5207 − 2.056529 = −5.577229 eV/atom ≤ 0`，判为预测稳定；真实 hull `−1.512202 ≤ 0` 判为真实稳定，该行进入 TP 侧，与脚本一致。F1 为无量纲比值，与 eV/atom 量纲无关；`abs(F1 − 0.935)` 同样是 F1 差值，不是能量差。
