## 四、冠军 F1 四格与门槛自检

样本域为 `unique_prototype=True` 的全化学体系，共 215,488 项（与用户给定值、`freeze.json`、reference 三处一致）。预测距离 `d = 冠军 e_form_per_atom − (e_form_per_atom_mp2020_corrected − e_above_hull_mp2020_corrected_ppd_mp)`，`d ≤ 0` 判预测稳定。

| 项 | 数值 |
| --- | ---: |
| TP（预测稳定且真实稳定） | 30939 |
| FP（预测稳定、真实不稳定） | 2326 |
| FN（预测不稳定、真实稳定） | 2003 |
| TN（双否） | 180220 |
| 四格总和 | 215488 |
| 精确率 TP/(TP+FP) | 0.9300766571471517 |
| 召回率 TP/(TP+FN) | 0.9391961629530691 |
| F1 = 2TP/(2TP+FP+FN) | 0.9346141646653677 |
| abs(F1 − 0.935) | 0.0003858353346323229 |
| 门槛 abs ≤ 0.02 | **PASS**（余量 0.019614164665367678） |

四格总和等于样本域规模，`TP+FN = 32942`（真实稳定数）、`TP+FP = 33265`（预测稳定数），代入公式 `2×30939/(2×30939+2326+2003)` 得 0.9346141646653677。门槛只做登记，未据此调任何参数、未换模型、未改名单。

## 五、含氧名单分析要点

- 含氧候选数由两条独立路径各数一次（标准库化学式解析、pymatgen `Composition`），结果均为 **23,821**，与给定值一致；`inputs/blind/unlabeled_candidate_pool.csv` 的 23,821 行全部含氧且 ID 集合与本轮识别结果完全相等。
- S、C 两策略 2000 档各 2000 个 ID **全部含氧（逐档 100.00%）**，说明冻结名单建在含氧子池上。因此含氧命中数等于总命中数，两列不可相加。
- 含氧子集四格（n = 23,821）：TP 2808、FP 236、FN 150、TN 20627，F1 = 0.9356881039653449，比全体系高 0.0010739392999771225；子集真实稳定率 12.417615% 反而低于全体系 15.287162%。该 F1 仅作对照，**不替代主指标**（分母不同）。
