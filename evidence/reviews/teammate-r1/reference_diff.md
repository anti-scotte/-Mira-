## 六、单位与量级核对

被比较的两侧都是凸包距离，单位 eV/atom：预测分数列与原始 DFT 距离列同量级（前 20 名集中在 −1.5 至 −0.3 eV/atom），两者之差多数在 0.001–0.01 eV/atom 量级，符合"预测误差"的预期量级；明显的例外是 S 名次 18 的 `wbm-4-26594`（Ba2 Fe1 O6 Pa1），预测 −0.309792 对 DFT −0.008852，差约 0.301 eV/atom——预测严重偏负但 DFT 仍判稳定，故不影响命中。而 `abs(F1 − 0.935) = 0.0003858353346323229` 与门槛 0.02 都是无量纲的 F1 差值，不带 eV/atom 单位——终稿第二节对此有同样声明，本轮沿用同一表述，避免把 F1 差读成能量差。

手工抽查一行，把三步算术写全（数据取自 `raw/64706751.gz` 与 `raw/70836372.gz`，未做任何四舍五入）：材料 `wbm-3-56891`（F4 O4 Pa4，名次 1）的 `e_form_per_atom_mp2020_corrected = −3.528853`，`e_above_hull_mp2020_corrected_ppd_mp = −1.512202`，于是 `e_ref = −3.528853 − (−1.512202) = −2.016651 eV/atom`；冠军预测 `e_form_per_atom = −3.5207`，故 `d = −3.5207 − (−2.016651) = −1.504049 eV/atom`，与表中 −1.5040490000 一致（末位差 6e−16 属 float64 表示）。同一材料的真实稳定判定用 `e_above_hull = −1.512202 ≤ 0`，故命中为 1。再抽查一个两侧互换的材料 `wbm-1-36714`（Cs2 O4 Pt2，S 名次 20、不在 C 前 20）：`e_ref = −1.295292 − (−0.310120) = −0.985172`，`d = −1.2922 − (−0.985172) = −0.307028`，预测稳定成立、DFT 距离 −0.310120 ≤ 0 命中，与终稿第四节点名的"仅 S 独有命中"一致。

## 七、reference 自述待办与本轮证据的关系

终稿第十一节列了 5 条待办，本轮能提供证据的是其中两条，另三条明确不在本岗范围：
