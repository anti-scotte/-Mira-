## 3 F1 门槛：未通过

**样本与定义。** 分母为全体独特原型：`unique_prototype == True` 共 **215,488** 行（`False` 41,475 行，第三态 0 行），由 WBM 表直接重算所得，可被输入表逐行复现。预测稳定判据为预测凸包距离 `d = e_form_per_atom − e_form_per_atom_mp2020_corrected ≤ 0`，与冻结协议中 d 的定义同一式、同一参考能列；真值稳定判据为 `e_above_hull_mp2020_corrected_ppd_mp ≤ 0`。23,821 个含氧候选仅用于本项目筛选比较，不进入 F1 分母。

|---|---|
| 实际参与复算的材料数 | **215,488**（= 分母） |
| TP / FP / TN / FN | 14,174 / 91,346 / 91,200 / 18,768 |
| Precision | 0.134325 |
| Recall | 0.430271 |
| **实算 F1** | **0.2047348731** |
| **模型卡 F1** | **0.935** |
| **绝对差** | **0.7302651269** |
| 容差 / 判定 | 0.02 / **未通过** |

**缺失与受影响范围。** 真值缺失 0 个、参考能缺失 0 个、预测缺失 0 个、ID 重复 0 个、非有限值 0 个，跳过 0 行。也就是说 215,488 个原型全部参与计算，没有因数据缺失而缩小的分母、没有近似填充值。受影响范围是**全池**：门槛不通过影响的是"本轮是否可以据 F1 指标解释命中结果"这一判断，而不是某一部分材料。按任务约束，不填近似值、不改冻结件、暂停解释，命中计数仅作为可复核底稿照算。

**差值来源的诊断（只读，不改变上述结论）。** 三条互相独立的证据指向"口径不一致"而非数据错误：

- 把真值列换成同表的校正形成能 `e_form_per_atom_mp2020_corrected ≤ 0`，同一预测得 F1 = **0.992392**（TP 186,715 / FP 1,971 / FN 892）。0.935 位于 0.2047 与 0.9924 之间，说明它对应第三种口径。
- 凸包距离与形成能不是同一判据：形成能 ≤ 0 的 187,607 个原型中，有 154,665 个实际在凸包之上；用形成能符号代替凸包判据会把假阳性放大一个数量级。
- 模型卡伴随字段 `finite = 23821`、`coverage = 1.0`、`DAF = 6.089` 中的 23,821 正是含氧候选池行数，而本轮分母是 215,488，两者相差 9.05 倍，提示 0.935 定义在含氧池上且很可能是排序类指标。

这些只用于说明差从哪来，未用于替代官方值，也未回填模型卡。

## 4 命中计数：S 20/20，C 20/20，差 0 个

沿用已验签的冻结前 20 名单，按 `material_id` 一对一关联 `e_above_hull_mp2020_corrected_ppd_mp`，有限值 ≤ 0 eV/atom 记为命中（含零，无容差）。两份名单各 20 行、20 个唯一 ID、名次 1–20 连续，关联结果无重复、无缺失、无非有限值，因此不需要报错中断。

| 名单 | 行数 | 唯一 ID | 命中数 | 未命中 |
|---|---|---|---|---|
| S（冠军单模型） | 20 | 20 | **20/20** | 0 |
| C（15 模型中位数共识） | 20 | 20 | **20/20** | 0 |
| 差 Hits(C) − Hits(S) | — | — | **0** | — |

两名单并集 22 个材料中，唯一贴近阈值的是 `wbm-4-26594`，DFT 凸包距离 −0.008852 eV/atom（S、C 两侧同一材料），仍在命中区内；其余 21 个材料分布在 −0.30364 至 −1.512202 eV/atom，命中裕度充足，结果不依赖阈值边界的四舍五入。

**为什么 20/20 与 F1 = 0.2047 不矛盾。** 两个口径的判据方向相反：F1 只让预测凸包距离 ≤ 0 的材料进入"预测稳定"集合，所以像榜首 `wbm-3-56891` 这样预测 d = +0.008153 eV/atom 的条目在 F1 里是假阳性；而命中核算问的是这 20 个材料在 DFT 里是否稳定（其 DFT 凸包距离 −1.512202 eV/atom），答案是是。前者评价模型整体的判别质量，后者只核对被挑走的 20 个材料的真值，两者本来就不是同一个问题；这也是门槛未通过时不宜把 20/20 当作优势结论的原因。

## 5 自洽核对：总差与独有命中之差

两个名单集合的差异恰好是 2 换 2：仅 S 有 `wbm-1-36714`、`wbm-1-38115`，仅 C 有 `wbm-2-35012`、`wbm-3-52495`；交集 18 个。在命中全中的情况下，这 4 个差异项各自都是命中，于是：

- 仅 C 独有命中数 = 2（`wbm-2-35012`、`wbm-3-52495`）
- 仅 S 独有命中数 = 2（`wbm-1-36714`、`wbm-1-38115`）
- 仅 C 独有命中 − 仅 S 独有命中 = 2 − 2 = **0**
- 总差 Hits(C) − Hits(S) = 20 − 20 = **0**

**核对等式 0 = 0 成立**，两侧独有命中之差与总差一致。这条恒等式在数学上恒真，本轮的意义在于实测两侧数值确实满足它，且 4 个独有命中 ID 与名单差异 ID 逐一对应，说明没有隐藏的关联错位或名单错配。

## 7 复核方法（供另一位真人独立重算）

本轮做了两套互不共享代码的实现：主脚本逐行 `csv` + `math` 比较，复核脚本用 pandas 向量化 + `merge(validate="one_to_one")`；两套得 TP/FP/TN/FN 14,174/91,346/91,200/18,768、F1 0.2047348731、S 20/20、C 20/20，逐位一致。另做了三项自检：两份 CSV 与冻结名单的 `rank`+`material_id` 与分数 repr 逐行相同；化学式与 WBM 表一致；三列数值全表范围分别为 −4.55…2.50、−4.56…4.74、−2.73…6.48 eV/atom，无 |x| > 10 的荒谬值，排除 eV 总量与 eV/atom 混淆。

复算入口为 `scratch/stage3/reveal_accounting_FINAL.py`（主）、`scratch/stage3/independent_recompute.py`（独立复核）、`scratch/stage3/selfcheck.py`（交付前自检），运行命令为在该任务目录下 `python3 <脚本>`；环境为 Python 3.11.15、pandas 2.2.3、numpy 1.26.4，与 `model_manifest.json` 登记的版本一致。所有事实快照在 `scratch/stage3/out/account_facts.json`。
